# rclone-backup-oauth

Home page for a personal Google OAuth client used with [rclone](https://rclone.org).

The client exists so that a single Raspberry Pi can copy security-camera
recordings from its local disk into the owner's own Google Drive on a timer.
It has one user: the account owner. It is not offered to anyone else and
there is nothing to install.

See [PRIVACY.md](PRIVACY.md) for the privacy policy.
